# max_tg_gateway

Telegram-бот слушает сообщения; когда сообщение приходит от заданного отправителя, программа пересылает его текст и/или фото в указанный групповой чат мессенджера MAX.

## Конфигурация

Файл `ini.toml` необходимо создать рядом с `main.py` (или рядом с исполняемым файлом), используя `ini.toml.example` как шаблон:

```toml
[max]
token = "ваш-токен-бота-MAX"

[telegram]
on = "yes"
token = "токен-Telegram-бота-от-BotFather"

[tg_to_max]
"TG_ID_отправителя" = "ID_группового_чата_MAX"
```

- **Мессенджер МАХ**: `token` — токен бота, которым мост отправляет сообщения в чаты MAX.
- **Telegram**: `token` — токен бота от [@BotFather](https://t.me/BotFather).

### Таблица пересылки

Секция `[tg_to_max]` — таблица соответствия «ID отправителя в Telegram → ID группового чата MAX»:

```toml
[tg_to_max]
"111111111" = "-1001234567890"
"222222222" = "-1009876543210"
```

Когда Telegram-бот получает сообщение от отправителя с указанным ID, программа пересылает его (текст и/или фото) в соответствующий групповой чат MAX через `chat_id`. Строк может быть несколько.

Требования для работы: `[telegram] on = "yes"` с токеном бота, непустой токен MAX в `[max] token`, и хотя бы одна строка в `[tg_to_max]`.

Как узнать нужные ID:
- **TG_ID отправителя** — числовой id пользователя Telegram (можно посмотреть, например, через @userinfobot, или временно логировать `message.from.id`).
- **ID чата MAX** — идентификатор группового чата в MAX.


Для сборки необходимо выполнить:

```bat
build.bat
```

Файл `ini.toml` необходимо поместить рядом с dist\max_tg_gateway.exe.
